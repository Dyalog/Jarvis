    The page opens GET /clock with EventSource; Send posts to /say, which Jarvis
    broadcasts to every open stream. Try a second browser window. If the server restarts, the browser reconnects by itself
    and sends the Last-Event-ID of the last tick it saw, so the welcome message says "Welcome back". Jarvis also sends
    heartbeat comments to keep the connection alive; browsers don't pass comments to the page, so they don't show up here.
